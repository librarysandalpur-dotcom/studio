# **App Name**: Sanskriti Library

## Core Features:

- Seat Booking & Availability: Allows users to view real-time seat availability and book seats online via a dynamic calendar.
- Membership Management: Admin dashboard for managing user memberships, tracking payments, and updating pricing plans.
- Admin Content Management: Admin interface for updating website text, uploading gallery images, and managing key information.
- Biometric/QR Entry System Integration: Secure access to the facility using biometric or QR code scanning integrated with user membership status.
- Inquiry Form: Contact form for prospective members to enquire about pricing plans and schedule a visit.
- Image Optimization: Leverage AI to resize and optimize images automatically for different devices, improving loading speeds and overall website performance.
- Dynamic FAQs: Utilize a retrieval-augmented generation tool to help respond to customer queries.

## Style Guidelines:

- Primary color: Deep indigo (#4B0082) for a premium and focused atmosphere.
- Background color: Very light grey (#F5F5F5) providing a clean, distraction-free environment in line with a light color scheme.
- Accent color: Muted violet (#8A2BE2) to highlight key interactive elements without disrupting focus.
- Body and headline font: 'Inter', a sans-serif for a modern, machined, objective and neutral look suitable for both headlines and body text.
- Clean, minimalist icons representing the facilities and amenities, with a touch of glassmorphism effect.
- Mobile-first responsive design with a grid-based layout, soft shadows and layered elements for a premium feel.
- Subtle animations and transitions for a smooth, modern user experience, giving an aspirational, world-class touch.
